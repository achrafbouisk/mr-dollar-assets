# mr-dollar-assets

Files for the "Mr. Dollar" live-interview class presentation.

- `front.jpg`, `back.jpg`: scans of a US $1 bill (series 2021). US currency designs are public domain.
- `site/index.html`, `site/stage.html`: the web pages. The Vercel site serves them from here, so a push updates the live site within about 5 minutes.
